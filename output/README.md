# 输出

- `inputs_*`：固定种子的查询子样本、原始索引、输入哈希和训练数据库特征统计。
- `smoke_*`：独立配置的模型、标签归一化器、训练日志、重载日志、逐查询预测和核验摘要。
- `reproduction_summary.json` / `verification.json`：便于合作查看的最终执行证据。
- `environment.txt`：此次实际安装的依赖版本。

模型和逐查询大文件仅本地保留，不提交 Git。模型重载核验后删除重复模型副本；保留真正需要复用的 checkpoint。
`smoke` 结果证明流程能运行，不代表论文完整精度复现。每个运行目录绑定输入、源代码和超参数哈希，配置变更不能默默复用旧模型。
